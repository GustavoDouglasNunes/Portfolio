# 🎯 Portfólio Gustavo - Sistema de Login + Portfólio

Portfólio pessoal responsivo com sistema de autenticação via localStorage.

## ✨ Funcionalidades

- ✅ Sistema de login com email
- ✅ Autenticação com localStorage
- ✅ Página de portfólio protegida
- ✅ Design moderno com glassmorphism
- ✅ Responsivo para mobile/tablet/desktop
- ✅ Botão mostrar/ocultar senha
- ✅ Navegação com Bootstrap

## 🛠 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos customizados + responsivo
- **JavaScript** - Interatividade e autenticação
- **Bootstrap 5** - Framework CSS
- **Tailwind CSS** - Utilidades (portfólio)

## 📁 Estrutura do Projeto

```
├── login.html           # Página de login
├── portfolio.html       # Página de portfólio (protegida)
├── script.js           # Lógica JavaScript compartilhada
├── style.css           # Estilos customizados
└── assets/             # Pasta para imagens (não incluída)
    ├── 1772426236844.jpeg          # Foto de perfil
    └── Blue_particle_tech_...jpg   # Background login
```

## 🚀 Como Usar

### 2. **Abrir no navegador**
- Abra `login.html` no navegador
- Digite qualquer email
- Clique em "Login"
- Será redirecionado para o portfólio


## 📱 Responsividade

- ✅ Mobile (< 768px)
- ✅ Tablet (768px - 1024px)
- ✅ Desktop (> 1024px)
